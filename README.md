# 까딱 · KKADDAK — Web Lab v0.3.3

PDF v2 설계를 반영한 웹 검증 버전입니다. 실제 MediaPipe 손 관절 결과로 사이트 내부의 가상 커서·버튼·카드·스크롤 문서·창을 조작합니다. Windows 단축키를 등록하는 것과 OS 명령을 실행하는 것은 별개입니다. 이 버전은 OS 입력을 보내지 않습니다.

## Windows 빠른 실행

1. ZIP 전체를 압축 해제합니다. 기존 개발 폴더를 수정했다면 먼저 백업하세요.
2. Node.js LTS를 설치합니다. Node 22.12 이상 또는 24 LTS를 권장합니다.
3. `start-windows.cmd`를 더블클릭합니다. 빌드·모델·WASM을 포함해 npm 설치나 API 키·DB가 필요 없습니다.
4. 카메라 연결을 누르고 권한을 허용합니다. 선택한 손바닥을 **3초 유지**하면 제어가 시작됩니다.
5. 화면을 바꾸거나 Esc로 중지한 뒤에는 **시작 제스처 감지 켜기**를 누르고 손바닥을 3초 유지합니다.

주소는 `http://127.0.0.1:5173/`입니다. 실행 창을 닫으면 서버가 종료됩니다. `index.html`을 파일로 직접 열지 마세요. macOS/Linux에서는 `node scripts/serve-built.mjs`로 같은 서버를 실행합니다.

## 기본 조작과 시험값

| 목적 | 동작 |
| --- | --- |
| 시작 | 선택한 손바닥 3초. 카메라 연결 후 감지하며 명령 실행은 완료 후 시작 |
| 이동 | 손바닥을 펼쳐 움직이기. 이동 복귀 시 첫 기준점을 다시 잡아 점프 완화 |
| 정지 | 선택한 손 주먹 |
| 클릭 메뉴 | 주먹으로 정지 → 검지만 펴서 유지. 구부리기는 필요 없음 |
| 메뉴 선택 | 위 클릭 / 오른쪽 더블클릭 / 왼쪽 우클릭 / 아래 취소는 시험 배치 |
| 메뉴 취소 | 주먹 또는 손바닥. 손바닥은 이동으로 복귀 |
| 드래그 | 엄지·검지 집기 → 유지 이동 → 벌려 놓기. 손 전체를 펼칠 필요 없음 |
| 스크롤 | 붙인 검지·중지를 펴고 손끝을 아래/위로 향한 채 유지 |
| 전체 해제 | 양손 주먹 3초. 준비 첫 순간 드래그 해제, 완료 후 중립 복귀·새 시작 필요 |
| 강제 중지 | Esc 또는 즉시 제어 중지 버튼. 대기 시간 없이 입력 취소 |

메뉴를 열 때 편 검지는 곧바로 선택에 쓰지 않습니다. **검지를 편 채 손 전체를 메뉴 방향으로 조금 옮기고 유지**하세요. 검지 각도를 꺾을 필요가 없습니다. 위 이동=클릭, 오른쪽 이동=더블클릭, 왼쪽 이동=우클릭, 아래 이동=취소는 시험 배치입니다. 메뉴 안의 주황색 이동점만 움직이고 실제 클릭 커서는 원래 대상에 고정됩니다. 중앙·작은 떨림·모호한 대각선은 선택하지 않습니다.

주먹에서 검지를 펴는 중의 반 구부림은 최대 1.5초 준비 상태로 유지합니다. 목록 진입 게이지를 채우는 중 220ms 이내의 반 구부림·미분류는 보류하며 유효 검지 시간만 누적합니다. 이 구간에는 여분 구부림 기능이 실행되지 않습니다. 임계값은 실기기 시험 대상입니다.

3초는 시작·해제의 고정 시간입니다. 시작 손바닥·해제 양손 주먹은 검증할 기본안입니다. 메뉴 진입 350ms·선택 300ms는 조정 가능한 시험값입니다. 게이지는 커서 둘레에서 12시부터 시계방향으로 채워집니다. 메뉴 중 커서는 고정되며 선택 후 중립으로 복귀하기 전 반복 실행하지 않습니다. 메뉴는 10초 미선택 시 취소합니다.

다른 손이 나타나도 한 손 커서 제어권은 선택 손에 남습니다. 중복 좌우 라벨은 대기 처리합니다. 추적 상실은 즉시 가상 버튼을 놓고 재개 전 손바닥 확인을 요구합니다. 결과 수신이 900ms 넘게 멎으면 감지 자체를 중지합니다. 이 값도 실기기에서 확인해야 합니다. 복잡한 교차·가림에서 동일 인물의 동일 손을 완벽히 추적하는 시스템은 아닙니다.

## 방향 유지 스크롤

실험실의 **스크롤** 탭에서 검지·중지를 붙여 펴고 유지하세요.

- **손끝 아래 → 아래로 스크롤**: 아래쪽 내용이 나타납니다.
- **손끝 위 → 위로 스크롤**: 위쪽 내용이 나타납니다.
- 손가락을 수평으로 돌리거나 자세를 풀면 멈춥니다. 주먹·손바닥·추적 상실·제어 해제 때도 멈춥니다.
- 같은 방향을 250ms 확인한 뒤 연속 입력을 시작합니다. 방향 전환 때도 다시 확인합니다.
- 내 설정 → 기본 조작 설정 → **스크롤 속도**에서 100~1200px/s를 조절합니다. 기본은 **보통 400px/s**입니다.
- 속도는 프레임 수가 아닌 경과 시간으로 계산합니다. 큰 추론 공백은 큰 스크롤 점프로 이어지지 않도록 제한합니다.

이 버전에서는 이전의 손끝 쓸기·반복 복귀·이동량 임계값 설정을 제거했습니다. 이전 설정에서는 손 선택·반전·감도 등은 유지하고 스크롤 속도만 400으로 초기화합니다. 기본 속도와 방향 판정의 실기기 적정성은 추가 확인이 필요합니다. 손 그림은 기존 AI 일러스트를 회전 표시한 설명 자료입니다.

## 기능 목록과 사용자 연결

내 설정의 **기능 목록**에 Windows·브라우저·편집·파일·미디어·접근성 추가 기능 75개를 등록했습니다. 기본 조작 7개·보류 항목 1개를 합쳐 총 83개 행입니다. 복합 항목의 좌/우·위/아래는 각각 나누어 표시한 경우가 있습니다. 카탈로그는 PDF 기준 설명 데이터이며 설치형의 실제 동작 검증 보고서가 아닙니다.

추가 기능은 처음에는 모두 **제스처 미지정**입니다. 기능 선택 → 여분 제스처 선택 → 카메라로 명령 없는 연습 → 충돌 확인 → 저장 순서입니다.

- V·검지 구부리기는 기존 인식기가 구별하는 여분 후보로만 제공하며 아직 실기기 검증 완료 상태가 아닙니다.
- 같은 손·웹 영역·제어 실행 상태·같은 자세의 기존 연결이 있으면 기존 기능과 충돌 조건을 표시하고 저장을 막습니다.
- 다른 실제 앱을 포커스로 구분하는 실행기가 없으므로, 현재 웹에서는 대상 앱이 달라도 같은 영역의 충돌로 봅니다.
- 유사 동작은 비교 경고를 표시합니다. 완벽한 자동 유사도 판정은 없습니다.
- 연습 확인은 자세를 650ms 유지한 결과이며 인식 정확도 검증 완료를 뜻하지 않습니다.
- 저장된 추가 연결을 실험실에서 취하면 **기능 이름·명령 미리보기와 로그만 표시**합니다. 복사·창 닫기·파일 변경·미디어 키 등 실제 명령은 보내지 않습니다.
- 연결 해제·추가 연결 기본값 복원·기본 설정 JSON 내보내기/가져오기를 제공합니다.
- 기본 이동·정지·메뉴·드래그는 필수 경로 보호를 위해 고정했습니다. 사용자 추가 기능 연결과 분리되어 있습니다.

## 양손 후보와 보류

양손 확대·축소는 웹 가상 창의 연속 배율 변화 시험입니다. Windows 배율 단축키와 자동 연결하지 않습니다.

**양손 상하 → Win + D**는 양손 행동 탭에서 명시적으로 켜는 후보이며 기본 꺼짐입니다. 같은 토글 명령을 사용하고, 외부 창 변경 모사 버튼으로 상태 변화 후 결과가 달라질 수 있음을 확인합니다. 실제 OS 상태를 읽거나 복귀를 보장하지 않습니다.

모든 창·페이지 종료와 양손 검지 X는 보류입니다. 연결·실행할 수 없습니다. 보조 손 Ctrl·Shift, YOLO 펜·도구, 커서 꾸미기·놀이·발표·사진 모드, 설치형·로그인·DB·커뮤니티는 추후 범위입니다.

## 저장·개인정보·검증 범위

- 영상은 서버에 전송·저장하지 않고 모델·WASM도 로컬에서 로드합니다.
- 좌우 반전 기본값은 꺼짐입니다. v0.3에서 넘어오면 다른 설정은 유지하고 반전만 한 번 꺼진 기준으로 옮깁니다. 이후 사용자가 켜고 저장한 보정은 유지됩니다. 카메라 아래의 선택/감지 손 표시로 비교하세요.
- 설정은 계정이 아닌 현재 브라우저 프로필·사이트 주소에 localStorage로 저장합니다.
- v0.2 설정에서는 유효한 손 선택·반전·감도만 옮기고, 옛 구부리기 메뉴·1초 일시정지는 새 기준으로 교체합니다.
- 실행 로그는 탭 메모리 최대 200개이며 새로고침하면 사라집니다. JSON·CSV 내보내기를 제공합니다.
- 직접 마우스 조작 횟수와 실제 손 인식 성공 횟수를 분리합니다.
- 손 그림은 PDF v2의 AI 일러스트를 추출해 사용했습니다. 실제 사진·학습 데이터가 아닙니다.
- 테스트는 상태 로직·UI 확인이며 실제 웹캠 정확도나 지연 성능을 측정한 결과가 아닙니다. `docs/verification.md`를 보세요.

## 개발

```bash
npm ci
npm run assets
npm run dev
```

Windows에서는 `develop-windows.cmd`를 사용할 수 있습니다. 개발 의존성 설치에는 인터넷이 필요합니다.

```bash
npm test
npm run build
```

코어는 `packages/core/src/controller.ts`, 기능 데이터·충돌 검사는 `packages/core/src/catalog.ts`, 연결 UI는 `apps/web/src/FunctionSettings.tsx`에 있습니다. 카메라 hook과 Worker는 별도입니다. Worker를 수정한 경우 `npm run assets` 후 카메라를 다시 연결하세요.

제3자 라이선스는 `THIRD_PARTY_NOTICES.txt`, 모델 출처·해시는 `public/mediapipe/model-info.json`에 있습니다. MediaPipe 사전 학습 손 모델을 사용하며 새 손 인식 모델을 학습한 결과물은 아닙니다.

## v0.3.1 인식 보정

엄지·검지가 겹치는 주먹은 집기보다 먼저 구분합니다. 집기는 두 손끝 거리뿐 아니라 검지의 뻗은 정도·손바닥 밖 위치·엄지 확장도 함께 검사하고 200ms 유지 후 드래그를 시작합니다. 실제 손의 오분류율은 사용자 웹캠에서 추가 검증해야 합니다.
