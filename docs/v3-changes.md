# v0.3 변경 범위

기준: KKADDAK 제스처·기능 설계 전달서 v2. 설계 합의와 미검증 후보를 구분합니다.

- 구부리기 필수 메뉴를 주먹 선행→검지 유지 메뉴로 교체.
- 선택 손바닥 3초 시작·양손 주먹 3초 전체 해제. 이전 1초 일시정지 토글 제거.
- 제어 해제 > 메뉴/드래그 > 양손 > 추가 기능/한 손 명령 순서로 정리.
- 메뉴·드래그·스크롤에서 커서 고정 또는 모드 독점, 재개 시 상대 좌표 기준점 재설정.
- 가로 손끝 스크롤 시험·양방향/한 방향 반복·임계값 설정 추가.
- Win+D 상하 후보 기본 꺼짐·가상 토글·외부 상태 변경 모사.
- 기능 카탈로그 83개 행(추가 75, 기본 7, 보류 1). 초기 추가 연결 없음.
- 여분 후보 V·검지 구부리기 / 명령 없는 카메라 연습 / 조건 충돌 검사 / 저장·연결 해제.
- 추가 연결을 인식하면 이름과 단축키 미리보기·로그만 생성. 실제 OS 입력 없음.
- v2 AI 일러스트 설명용 적용. 모델 학습·실제 데이터로 사용하지 않음.
- 기본 설정 schema 3 및 추가 연결 저장소 분리. 구버전 기본 제스처는 새 기준으로 교체.

아직 실사용 검증이 필요한 항목: 손 인식 정확도·가로 자세·복귀 스트로크·손 교차·가림·시간값·후보 손 모양·메뉴 방향.
추후 범위: YOLO 펜/도구, 보조 손 보조키, OS 실행기, 설치형·인증·DB, 커뮤니티, 꾸미기·놀이.
