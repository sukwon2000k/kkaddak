# v0.2 화면 개편

## 바뀐 사용 흐름

1. 카메라 연결 → 권한 허용 → 왼손/오른손 선택 → 손 확인 → 테스트 시작.
2. 클릭·드래그·양손 행동을 탭으로 구분. 테스트 전환 시 제어 중지 후 다시 시작.
3. 집중 모드는 소개 영역을 접고 조작 영역을 확장. 제어 시작 시 자동 적용.
4. 가이드·설정·기록으로 이동하면 제어만 멈추고 카메라 연결은 유지. 별도의 카메라 끄기 제공.
5. 다음 행동·현재 모드·입력 출처를 구분해 표시. FPS 등 진단 수치는 접어서 제공.

## 시각 체계

보라색을 주요 동작에, 파랑·코랄·크림색을 테스트 구분에 사용합니다. 초록색은 입력 준비·연결 상태에 한정합니다. 카메라는 어두운 프리뷰 영역으로 구분하고, 테스트 목표는 크고 선명한 카드로 표시합니다. 설정 오류는 해당 설정 옆에서 설명합니다.

## 유지한 범위

손 인식은 로컬 MediaPipe를 사용합니다. 브라우저 내부 테스트이며 실제 OS 입력 제어·로그인·DB·YOLO 도구 인식은 포함하지 않습니다. 시험 동작과 정지·재개 정책은 기존 제어 코어를 유지합니다.
