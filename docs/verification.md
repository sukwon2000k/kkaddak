# v0.3.3 메뉴 진입·손 이동 선택 — 2026-11-17

- TypeScript 타입 검사·Vite 프로덕션 빌드 및 합성 관절 상태 테스트 50개 통과.
- 주먹→반 구부림→검지의 자연스러운 전환, 준비 없이 진입 금지, 전환 유예 시간 초과, 짧은 구부림 보류와 유효 시간만 누적 확인.
- 구부림 추가 기능이 연결돼 있어도 기본 메뉴 전환 과정에서는 실행하지 않음 확인.
- 오른손·왼손 각각 손 전체를 상하좌우로 이동하여 클릭·더블클릭·우클릭·취소를 구분. 실제 이벤트의 클릭 좌표는 원래 커서 위치를 유지함을 확인.
- 검지 각도만 변경·중앙 유지·작은 떨림·모호한 대각선·유지 전 중앙 복귀에는 클릭하지 않음 확인.
- 메뉴 항목 변경 시 게이지 초기화, 단발 실행, 해제·스크롤 관련 기존 로직 회귀 확인.
- 실제 카메라에서의 자세 분류·물리적 이동 거리·편안함은 사용자 실기기 검증이 필요합니다. 합성 관절 테스트는 실제 인식 성능을 증명하지 않습니다.

아래는 이전 버전의 기록이며 검지 각도로 메뉴를 선택하는 항목은 손 전체 이동 선택으로 대체됐습니다.

# v0.3 검증 기록 — 2026-11-17

## 자동 검사

- TypeScript 타입 검사 및 Vite 프로덕션 빌드 통과.

- 합성 관절을 사용한 상태·충돌 로직 테스트 30개 통과.
- 3초 시작/전체 해제, 준비 즉시 드래그 해제, 새 시작 조건, 긴 결과 공백을 유지 시간으로 계산하지 않는 조건 확인.
- 주먹 선행 조건, 검지 유지 메뉴, 메뉴 중 커서 고정·손바닥 취소·방향 변경 초기화·단발 클릭·더블클릭·우클릭·10초 취소 확인.
- 드래그 독점·해제·추적 상실·900ms 결과 정지·비선택 손·중복 좌우 라벨·역순 결과 확인.
- 가로 스크롤 위/아래 방향·손 전체 이동 무시·한 방향 반복 복귀 무시·세운 V 제외 확인.
- Win+D 후보 기본 꺼짐·동일 토글 이벤트 확인.
- 추가 기능 동일 조건 충돌·보류 항목 연결 거절·웹 shortcut 이벤트만 단발 출력 확인.

## 브라우저 확인

- 4종 테스트 탭 및 내 설정의 기능 목록·제스처 모음집 렌더링.
- 추가 기능 75개 / 전체 83개 항목 표시. 닫은 탭 복원을 검색해 Ctrl+Shift+T·Chrome·복원 조건·제스처 미지정 표시 확인.
- 연결 대화상자의 손·여분 자세 선택, 혼동 경고, 카메라 연습 전 저장 비활성화, Esc 취소 확인.
- 모든 창·페이지 종료를 검색해 보류·연결 불가 표시 확인.
- PDF v2 손 그림 6종의 로드 확인. PDF의 별도 투명도 마스크를 합쳐 흰 배경으로 추출했으며 새 이미지를 만들거나 검증 데이터로 사용하지 않음.
- 스크롤 반복 설정을 아래 내용 반복으로 바꾼 후 새로고침해 복원 확인. 시험 후 기본값 복원.
- 스크롤 연습 문서가 실제로 스크롤 가능한 영역임을 확인.

## 확인하지 못한 부분

검증 환경에는 실제 웹캠·WebGL2가 없어 실제 손 관절 추론·인식 성능을 완료로 표시하지 않습니다.

- 카메라 연습→실제 손 인식 확인→저장 전 과정은 사용자 PC에서 추가 확인해야 합니다. 검증을 우회해 가짜 성공을 만들지 않았습니다.
- 합성 관절 테스트는 실제 손의 오작동률·거리·조명·좌우 판정·교차·가림 정확도를 증명하지 않습니다.
- 연속 스크롤의 임계값·한 방향 복귀 방식·양손 연속 배율은 시험 구현이며 실사용 최적값이 아닙니다.
- MediaPipe 좌우 분류와 중복 라벨 검사는 동일 손 ID의 완전한 추적 시스템이 아닙니다.
- Windows 실행기·보조키 실제 누름/해제·OS 포커스·Win+D 실제 외부 상태 동기화·설치형·로그인·DB는 포함하지 않았습니다.
- 모바일 실기기와 Windows CMD 더블클릭 실행은 이 환경에서 직접 검증하지 않았습니다.

## 사용자 PC 검증 순서

1. 카메라 연결 후 선택 손바닥 3초, 시작 게이지와 커서 확인.
2. 주먹→검지 유지로 메뉴를 열고 커서가 고정되는지 확인.
3. 방향 선택·손바닥/주먹 취소·손실 후 재개 위치 확인.
4. 집기 이동·벌려 놓기, 해제 준비 즉시 놓기·양손 주먹 3초 전체 해제 확인.
5. 가로 손끝 스크롤을 양방향/한 방향 반복 각각 비교. 전체 손 이동·복귀 스트로크 오인을 기록.
6. 추가 기능의 연습·저장·충돌 경고·연결 해제와 실험실의 모의 실행 기록 확인.
7. Win+D 후보를 켠 경우 외부 창 변경 모사 후 토글 결과를 비교.

측정하지 않은 성공률·지연시간 수치를 작성하지 않습니다.
